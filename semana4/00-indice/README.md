# Semana 05 — Animaciones SVG/CSS3 y Micro-interacciones UI

Material práctico construido a partir de la presentación S05_Animaciones.pdf.

## Orden sugerido para explicar la clase

1. `01-transicion/01-transicion.html` — transition: pasar de estado A a B.
2. `02-keyframes/02-keyframes.html` — @keyframes: animaciones con varios pasos.
3. `03-estados/03-estados.html` — :hover, :focus-visible y :active.
4. `04-loaders/04-loaders.html` — spinner, puntos y skeleton.
5. `05-boton-carga/05-boton-carga.html` — JavaScript + clases CSS + estado de carga.
6. `07-svg-check/07-svg-check.html` — check SVG que se dibuja.
7. `06-rendimiento/06-rendimiento.html` — left vs transform y Paint flashing.
8. `08-proyecto-tarjeta/tarjeta-inicio.html` — proyecto integrador.

## Cómo abrir

- Abre esta carpeta en VS Code.
- Ejecuta `index.html` de cada ejemplo con Live Server, o abre los HTML directamente en el navegador.
- Cambia un solo valor por vez y vuelve a cargar.

## Conceptos clave de la sesión

- `transition`: anima el cambio entre dos estados.
- `@keyframes`: define varios momentos de una animación.
- `:hover`: respuesta al puntero.
- `:focus-visible`: respuesta visible al teclado.
- `:active`: respuesta mientras se presiona.
- `prefers-reduced-motion`: respeta la preferencia de reducir movimiento.
- `transform` y `opacity`: propiedades recomendadas para animaciones eficientes.
- JavaScript puede cambiar clases; CSS controla la presentación y animación.
